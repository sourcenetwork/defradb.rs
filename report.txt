## Summary

Rewrites the FFI layer to cover the calls of Go DefraDB's cbindings (`libdefradb.h`), named `defra_<noun>_<verb>`. It matches Go's API, not its ABI: function and type names are prefixed (`Result` is a poor global name in C), and `NodeInitOptions` adds fields after Go's, so it is not a drop-in for `libdefradb.h`. Every call that works on a store takes **one handle naming a node or one of its transactions**, plus an **identity handle** (`0` for none). These replace the separate `*_in_txn` variants and DID-string arguments.

This branch is also merged with `main` (`5ba80b0b7`) and ported onto the APIs that changed underneath it. See [Merge with main](#merge-with-main).

## Merge with main

This PR started about 225 commits behind `main`. While it was open, `main` changed the code it touches in four big ways. Each was handled as follows:

- **`crates/embedded` was folded into `defra-node`.** The PR's embedded changes (several listen addresses, bootstrap peers, retry intervals, NAC at startup) were already upstream, so `main`'s side was taken. The FFI now builds nodes with `defra_node::NodeBuilder`.
- **The FFI transaction registry was removed (#2391).** A transaction's ID now travels in the `RequestContext`, and work goes through the node's executor (`runner.*_as`). The PR's "node or transaction handle" design stays: a transaction handle simply puts its ID in the context.
- **Logic moved into the core.** Adding, patching and truncating collections, lenses and migrations, DAC policies, dropping indexes, and Go-style collection lookup are now core functions. The FFI calls delegate to them instead of keeping their own copies.
- **The GraphQL builders and P2P types left the `http` crate.** Document writes now use `query::documents` (add, update, delete, by ID or filter). P2P calls use `defra_p2p_adapter::peer`, `main`'s single implementation of Go's P2P API. `defra-http` is no longer a dependency of `ffi`.

The PR's changes outside the FFI (`http`, `query`, a `db` patch helper) were dropped because `main` had already replaced them. Two features `main` added to the old FFI were carried over: peer details (now `defra_mobile_peer_details`) and the #2391 test that a transaction serves any caller identity. `main`'s replicator-completion event JSON was dropped, because this PR removes the event-bus subscriptions it belonged to. `tools/apple/README.md` now documents the new C API.

### Behaviour changes

- `store_type` accepts `regolith`, `memory` and `badger` only.
- `defra_p2p_connect` / `defra_p2p_disconnect` with no addresses fail with Go's `addresses cannot be empty`.
- `defra_p2p_document_list` answers with an array of document IDs.
- `defra_lens_list` answers in Go's `{"<id>": {"Lenses": [...]}}` shape.
